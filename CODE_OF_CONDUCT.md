# Code of Conduct

This project is built to serve people reading the Quran. Interactions among contributors must reflect that intent.

## Standards

Contributors are expected to:

- Be respectful, courteous, and patient.
- Assume good faith.
- Focus on the work; keep discussion technical and constructive.
- Treat the Quran text and religious sensibilities with the highest care and accuracy.
- Prefer clarity over cleverness; document decisions.

Contributors must not:

- Harass, insult, or demean others.
- Make personal attacks or discriminatory remarks.
- Publish others' private information.
- Introduce religious, political, or ideological polemic into the codebase or issues.

## Enforcement

Behavior violating this Code may result in warnings, temporary bans, or permanent removal at the maintainers' discretion. Reports go to the repository owner via the email in `git log` or GitHub's private reporting tools.
